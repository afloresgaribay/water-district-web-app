# Water District Customer Profile
Customer profile page for a water utility district - built with HTML showing account information and usage history

## Live Site
https://afloresgaribay.github.io/water-district-web-app

## What This Project Shows
- How to create an HTML page from scratch
- How to use headings to organize content
- How to build a data table with headers and rows
- How to display data

## The Data 

The page shows a sample customer account including:
- Customer name, account number, and account type
- Service address, account status and payment status
- Four months of water usage history in gallons
- Bill amount per billing cycle

## Built With
- HTML5 - structure and content only
